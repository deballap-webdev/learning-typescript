# TypeScript Learning Sandbox 📘

This repository is a dedicated practice space where I am learning TypeScript from scratch, following along with **Dave Gray's TypeScript Full Course**.

## 🎯 Course Chapters & Topics Covered
- [ ] **Chapter 1:** Start Here (Setup, `tsconfig.json`, & Compiling)
- [ ] **Chapter 2:** Basic Types (`string`, `number`, `boolean`, `any`, Union Types)
- [ ] **Chapter 3:** Arrays & Objects (Tuples, Type Aliases, Interfaces, & Enums)
- [ ] **Chapter 4:** Functions (Type Aliases, Optional/Default/Rest Parameters, `void`, & `never`)
- [ ] **Chapter 5:** Type Assertions & Type Casting (DOM manipulation & `as` keyword)
- [ ] **Chapter 6:** Classes (Visibility Modifiers, `implements`, Getters/Setters, & Static Members)
- [ ] **Chapter 7:** Index Signatures & `keyof` Assertions
- [ ] **Chapter 8:** Generics (Generic Functions, Interfaces, Classes, & `extends`)
- [ ] **Chapter 9:** Utility Types (`Partial`, `Required`, `Readonly`, `Record`, `Pick`, `Omit`, `ReturnType`, `Awaited`)
- [ ] **Chapter 10:** Vanilla TypeScript Project (Vite + TS Todo List App)
- [ ] **Chapter 11:** React + TypeScript Basics (Components, Props, & State)
- [ ] **Chapter 12:** React Hooks + TypeScript (`useState`, `useEffect`, `useCallback`, `useMemo`, `useRef`)
- [ ] **Chapter 13:** `useReducer` with TypeScript
- [ ] **Chapter 14:** `useContext` with TypeScript
- [ ] **Chapter 15:** React + TypeScript Shopping Cart Project
